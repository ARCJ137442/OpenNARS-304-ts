# NARS 2048 learning lab

## 目的与来源

将用户自己的 [jev-2048](https://github.com/ARCJ137442/jev-2048)（本地提交 `9582bcf`，MIT）作为规则、纯引擎、棋盘动效与可观测实验台的参考，在 OpenNARS 3.0.4 TS 静态 Demo Lab 中实现另一个独立的「NARS × 2048」Demo。复制/改写的源文件应保留 MIT 许可与具体来源；Jev 的远端 API、密钥、概率/成本语义**不照搬**。本项目改问：NARS 在连续多局中是否从真实操作—结果经验形成能改变决策的知识？

## 核心合同

- [ ] 用纯 TypeScript 游戏引擎实现四方向压实、每回合至多合并一次、合法方向、得分、新块生成、游戏终局；不修改试算输入。保留参考项目有实验价值的棋盘尺寸/生成分布/步进控制与可复现 seed，适配统一 Lab 的配色、布局、键盘和动效。
- [ ] 浏览器 Worker 的 `^up/^down/^left/^right` 是唯一自动行动接口；感知包含局面可操作特征，目标至少为复合词项，反馈包含合并/得分与无效移动结果。预置规则、NARS 自主操作、babble、人工操作和非法方向必须明确分色/分源，不用启发式动作伪装 NARS。
- [ ] 终局自动开新局并累计局数、得分与最高块；**默认复用同一个 NARS Worker/记忆**，另设明确的“重置 NARS 记忆”动作。棋盘重置、页面刷新、Worker 重建三者语义不同；显示当前记忆跨局保留状态。
- [ ] 页面展示棋盘、合并/新块/终局动效、操作来源、FPS/TPS/RPS、每局成绩轨迹与按需内部经验视图。页面遵守「一图胜千言」，减少动效仍可读。
- [ ] 提供可导出的匿名实验记录与中英说明：seed、设置、每步 NARS 输入/操作来源/反馈、局数、分数、概念规模、时间、Worker/核心提交。对“学到了多少”只做由真实事件和对照支持的声明。

## 验收

- [ ] 参考 `jev-2048` 引擎行为的直接合同及不修改试算输入测试通过；无私密 Jev API 或密钥依赖进入静态产物。
- [ ] 真实浏览器固定 seed 连续两局，证明自动重启只重置棋盘、NARS 时间与概念不归零；点击“重置记忆”后 NARS 才重新启动。
- [ ] 固定设置下分别记录保留记忆与每局重置的得分/最高块/有效操作和概念变化；至少观察一次非 babble NARS 操作。若没有学习差异，准确记为未观察到，不宣称提升。
- [ ] Demo 类型/构建/单测/浏览器门通过，首页不为 2048 启动 NARS Worker，GitHub Pages 子路径、原作者/MIT attribution 与版号一致。

本规格依赖 024 平台边界、044 统一 Lab、045 内部经验观察；与 046 网格 Microworld 是并列的新 Demo。LeanSpec `link` 子命令当前不可用，依赖以正文为准。
