# NARust-o Shot full multi-player port

## 目标与事实

用户要求现有简化 `Shot` 完整复刻其 NARust-o 多玩家射击游戏的规则与功能，再将交互、NARS 具身接口、FX 适配为 OpenNARS 3.0.4 TS Lab。来源为用户自己的 NARust-o `examples/_games/shot/`（本地提交 `cd685cd`，Cargo `MIT OR Apache-2.0`）；当前 Web Demo `src/games/worlds/shot.ts` 只有单玩家水平移动、移动靶、三操作与命中统计，**不能宣称原作已移植**。

## 源码模式矩阵

`shot/mod.rs` 有 `shot_test`、`shot_test2`、`shot_test_2p`、`shot_test_2p_2ai`、`shot_test_evolve`、`shot_test_evolve2` 六个公开入口。前两种是静态靶与单 NARS，分别使用绝对上下左右移动和相对转向/前进；中间两种是双 NARS 玩家，后一种混用 `AiNar`/`AiNar2`；进化模式按命中率与命中间隔排名，克隆优秀玩家、淘汰落后者并重生，至上限人数。`AiNull` 是静态靶；`Ai` 的感知→行动→射击反馈→推理周期四段不能遗漏。

## 必须复刻的世界合同

- [ ] 一个 50×20 离散世界（可视响应式缩放），玩家方向、位置、速度、朝向图形、射击状态、命中/漏射、距上次命中及平均命中间隔；边界阻挡、玩家不能占同一格，命中后被击者重生。
- [ ] 子弹/射线按原作“瞬时沿朝向命中同一行/列的首个其他玩家”，保留发射可见期、射击成功/失败反馈与世界步进顺序；原作的阻塞 `sleep` 改为不阻塞推理的等价视觉时间，不改变命中判定。
- [ ] 六种模式在**同一个 Shot Demo** 内切换，玩家数量与 `AiNar`/`AiNar2` 角色由模式配置决定；静态靶、双玩家与进化模式不混成同一种玩法。进化的排名、克隆/淘汰/重生条件与上限有直接合同；如果核心 NARS 记忆无法安全克隆，明确区分“复制环境角色/新 Worker”与“复制 NARS 记忆”，不得假称完全等价。
- [ ] 每名 NARS 玩家有独立 Worker、目标、感知、操作队列、NAR 时间/RPS/概念数与颜色；世界 TPS 独立于各 Worker。模式切换和增删玩家妥善终止或创建 Worker，旧消息不得串到新角色。
- [ ] ONA 专用 Narsese 改写为 OpenNARS 可解析的复合目标、操作条件和反馈；绝对/相对感知及无变化刷新语义做实测。预置知识、推导、babble 与人工控制分源；实际至少发出非 babble 的 NARS 操作，不以画面假动作过门。

## 表达与验收

- [ ] 场景以多角色可辨颜色/形状、方向、射线、命中/重生、排行变化和清晰的语义 FX 呈现；参数与深入的 NARS 经验视图渐进披露，符合“一图胜千言”和减少动效合同。
- [ ] 纯世界合同与参考源码逐项比对；六模式均有局部测试和固定 seed 的真实浏览器运行记录。多 NARS 模式须证明每个角色的独立 Worker 和内部状态，进化模式须实际发生一次克隆/淘汰与反馈。
- [ ] 每模式记录目标≥20 TPS、实际/目标、每 Worker RPS/RSS 或可得内存、有效操作和得分；若某模式因资源达不到目标或不能完全复刻，公开标明具体缺口，不能仍称“完整”。
- [ ] 保留 NARust-o 原始路径、提交与 MIT/Apache/ONA 来源致谢，新增逻辑标注 OpenNARS 适配差异；整体 Demo `npm run check`、浏览器及最终发行门通过。

本规格依赖 024 平台装配、044 统一 Lab、045 内部经验和 048 多 Worker Pong 的可复用编排；LeanSpec 当前无 `link` 子命令，只在正文记录依赖。

## 2026-10-04 基础模型进展

Demo 已新增独立 `src/shot-lab-model.ts` 与 `test/shot-lab-model.test.ts`，先落地不依赖 DOM/Worker 的世界合同：

- 六个 NARust-o 入口以一个模式表表达；模式差异包含绝对/相对移动、玩家数量、混合 NARS 接口和进化开关。
- 世界固定为 50×20；玩家有方向、位置、射击可见期、命中/漏射、上次命中间隔与平均间隔；移动不能进入已占格。
- 射击按朝向选择同轴最近目标，命中后目标重生并记录射线；感知和目标使用 OpenNARS 可解析的复合词项。
- 进化在第 500 刻按命中率选择优秀玩家并克隆一个环境角色；NARS 记忆克隆尚未宣称等价。

这批是模型基础，不是完整 Demo：页面、独立 Worker、六模式真实浏览器运行、射击 FX、进化过程可视化和发布门仍待完成。

随后 Demo `c0a27d3` 已接入 `shot.html` 页面与独立 Worker：六模式切换、同步/异步世界刻、玩家/射线 Canvas、经验观察和非 babble 操作已通过部署前缀浏览器 smoke；`c9d16ee` 又补上进化超过 500 刻后的新增环境角色 Worker，浏览器实际观察到角色数从 4 增至 5。原作“淘汰落后者”的完整排名策略、每 Worker 独立性能面板和最终发行门仍未完成，因此本规格继续保持 `in-progress`。

## 2026-10-04 进展更新

Demo `ca1ab39` 已把进化世界合同对齐到原作排名方向：适应性分数为四舍五入到 4 位精度的 `命中率 / (距上次命中刻数 + 1)`，升序排名后克隆最后一名、在参与排名者超过上限一半时淘汰第一名，玩家数小于上限时复制 2 个、等于上限时复制 1 个，并让克隆保留来源角色的统计与 AI 类型；所有存活角色随后统一重生。`stepShotWorld()` 返回有界 `rankings` 和 `EVOLVE:RANK/CLONE/EVICT` 依据事件，命中重生也已统一到同一随机重生合同。

纯模型合同已覆盖四舍五入排名、克隆统计继承、命中重生、移动阻挡与 500 刻进化；真实浏览器六模式、进化新增 Worker、页面构建和 65 项 Demo 测试通过。仍未完成的门是长期进化行为与 NARust-o 的逐步对照、每 Worker 更完整的性能面板、六模式长期固定 seed 记录和最终发行验收，因此不能把 049 标记为 complete。
