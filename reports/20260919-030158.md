## 任务过程笔记

- `Item` 虽然在 Java 中实现 `Serializable`，但 OpenNARS 当前运行路径没有序列化消费；它自身已经覆盖 Java Object 的业务可观察方法，因此可以只保留项目类身份边界。
- 去掉 `JavaObject` 后，`equals(java.lang.Object)` 不能继续把子类参数绑定到 jree 私有结构；对值对象相等接口使用 `unknown` 更符合 TypeScript 的运行时合同，调用点再做 `instanceof` 收窄。
- `TermLink.equals` 的哈希快速路径必须在 `TermLink` 类型收窄后执行；否则 `unknown` 参数无法安全调用外部对象的 `hashCode`，也会把非同类对象的类型边界重新带回 jree。
- S0 的“待做”文字曾落后于已提交事实；本批以 `current-status.md` 的复核条目和冻结证据为准，不重复用长测替代开发。
