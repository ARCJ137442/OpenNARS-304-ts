## 任务过程笔记

- jree 1.3.0 的 `java.lang.System` 没有 `java.util.logging.Logger`，直接沿用翻译后的 `java.lang.System.Logger` 会导致编译错误和潜在运行时 TypeError。
- 项目测试入口依赖 Node `--experimental-strip-types`；新增 TypeScript 必须避免 parameter property 等 strip-only 不支持的语法。
- 兼容层只在错误路径输出日志，正常推理路径不改变；异常对象优先调用 Java `printStackTrace()`。
- 测试类型阶段仍有 18 条 `BagPerf.ts` Logger 诊断，属于后续测试簇，不混入本生产批次。
