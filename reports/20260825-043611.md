## 任务过程笔记

- Java varargs 在 TypeScript 中既要表达逐项调用，也要表达迁移代码中直接传入数组的调用；只保留 `...Term[]` 重载不足以覆盖后者。
- 工厂的空结果是 Java 运行时契约，不能通过删除 `return null` 规避；本批把可空性放在实现边界，避免向所有调用方传播尚未整理的 API 设计变化。
- `Term.get("SELF")` 的 `string`/`CharSequence` 问题横跨多个文件，作为下一类独立迁移模式处理。
