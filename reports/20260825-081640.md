## 任务过程笔记

- `tsc` 输出含多行 overload 细节，统计必须只计算匹配 `error TS####:` 的首行，不能按物理行数统计。
- Java 的抽象重载不能直接在 TypeScript 中写成“一个具体实现 + 一个抽象 overload”；本批用独立字符串辅助方法避免破坏 VisionChannel 的 Task 重载契约。
- 初次把 Nar 时钟运行时值切换为 bigint 后，串行测试出现 5 项 number-bigint 混算/类型表示回归；恢复 number 运行时表示并保留 long 类型适配后，139 项全部通过。
- PowerShell 下 `npm run test:parity:local -- --java-jar ...` 会被 npm 解析为 npm 自身配置参数；直接调用 runner 并显式传入三个 artifact 路径后 parity 通过。失败命令证据保留在 `reports/evidence/local-parity-20260825-nar-sensory-contract.txt`。
- `java.io.ObjectOutputStream`、`java.lang.reflect` 并非当前 jree 类型表面的稳定 API，应通过局部兼容边界处理，不能为了消除诊断改写推理语义。
