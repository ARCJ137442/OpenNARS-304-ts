- Java `float` 语义的关键不是“每个表达式末尾都 `Math.fround`”，而是保留 Java 源码中变量声明、显式 cast 和赋值边界；如果两个操作数都是 `float`，操作数收窄的位置会影响离散调度。
- 预算的 1 ULP 差异可以先改变 NovelTask Bag 的 level，再改变概念取出顺序，最终表现为 RuleTables 或操作派发差异；因此应沿“数据结构 → 容器 → 推理规则 → 推理引擎”逐层定位，而不是先改最终 marker。:codex-annotation{index="1"}
- 单纯的最终字符串 parity 不足以定位调度分叉；本批使用 Concept/Task Bag 状态和事件序列确认了最早分叉点。
- 该模式已在 `DerivationContext` 和 `ProcessGoal` 两个推理引擎位置出现；当前只更新模式库，没有声称扫描器已能自动修复它。
- TypeScript 当前 `npx tsc --noEmit` 为 3513 条诊断；相对上一批约 3502 条增加 11 条，主要来自新增测试在现有非 ES module 配置下的 dynamic import 诊断，不能把 `tsc` 视为本批通过门禁。
