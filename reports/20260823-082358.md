## 任务过程笔记

- Java 的 `Nar.cycles()` 是同步循环；默认 `THREADS_AMOUNT=1` 不能只靠默认值作为验收证据，适配器必须显式写出单线程设置。
- marker 的“功能一致”和“耗时接近”是两个维度。超预算不能直接证明语义错误，反之 marker 一致也不能掩盖内部 TermLink/TaskLink 轨迹已经分叉。
- 部分 marker 有时间戳时只能记录观测值，不能输出完整预算通过；完整性字段必须先成立，才能解释 `within_budget`。
- 131072 周期的宽限条件必须以 marker 为中心：先确保所有输出 marker 都命中，再要求采集到的内部事件 marker 在规范化后逐点逻辑等价；仅有最终字符串一致时，最多记作输出层通过。
- 5248 周期分歧落在 TermLink 构建/递归顺序，而不是 parser 崩溃或 Java 多线程。一次临时的 `CompoundTerm` 数据形状兜底实验没有改变高周期轨迹，已撤回，避免把未经验证的结构性修补混入本批。
- 覆盖率工具默认只报告被测试加载的源文件；要覆盖整个 TypeScript 仓库，后续必须显式设计模块发现、入口测试和排除规则，不能直接把当前三文件报告称为全仓覆盖。
