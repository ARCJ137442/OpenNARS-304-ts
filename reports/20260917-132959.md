## Java 合同与因果边界

Java `CompoundTerm.getContainedTerms()` 使用 `Set<Term> s = new LinkedHashSet<>(getComplexity())`，逐项加入直接子项，并递归合并复合子项；`addComponentsRecursively()` 在收到 `null` 时创建 `LinkedHashSet<Term>`，先加入当前项，再按复合项的原顺序递归。两者的不可替代语义是：同一 Term 按 Java `equals` 只保留一次，迭代顺序是首次加入顺序。

本批只替换 Set 的实现，不改变方法的 Java 返回形状、递归顺序、TermLink/规则派发或调用者逻辑。`NativeSet` 底层使用原生数组只是存储策略；它仍通过独立的 Set 类型表达唯一性、值相等和插入顺序，避免把 Set 错当成 List 或数组。`CompositionalRules` 的两个目标/谓词分支确实消费 `addComponentsRecursively()` 的迭代结果，因此本批完成 M2 后追加 M1- 保护矩阵。
