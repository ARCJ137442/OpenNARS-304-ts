## 任务过程笔记

- `LinkedHashSet` 在此处的可观察要求不是“必须是集合类型”，而是 Java `equals` 驱动的去重查询；用顺序列表模拟 `contains + add` 能保持结果，同时避免为一次性小集合引入新的公共容器抽象。
- 该选择只适用于当前两个局部算法。Bag、TaskLink、Variables 等仍可能依赖哈希、对象 key、插入顺序或 iterator/remove，不能由本批结论批量替换。
- 本批验证口径按用户要求收窄：局部合同和 M2 覆盖单个小簇；只有整类 `Stamp` 证据基集合责任闭合后才运行一次串行 M1-，没有重复运行 #245 长期稳定性样本。后续同类小簇继续采用“局部合同 → 局部 M2 → 完整特性簇闭合时 M1-”闭环。
- `NativeList.contains` 是线性查找，当前只证明了 Java `equals` 判重的功能合同；Java 源码原本使用 `LinkedHashSet` 的复杂度优势仍是后续性能/容器专题，不在本批与逻辑修复混合处理。
