## 任务过程笔记

- Java `float` 不是“最终返回值再转一次”这么简单：配置读取、字段存储和参与运算前都可能是语义边界。当前最小可靠边界是配置字段白名单加 `Math.fround`，并在 `rankBelief` 返回处保持 binary32。
- `TRUTH_EPSILON` 的 Java 实际值为 `0.009999999776482582`，使 `1 - epsilon` 为 `0.9900000002235174`；TypeScript 若保留 `0.01`，会进入不同的 confidence clamp。这个微小差异足以改变后续 belief 排序。
- 有 marker 的样本不需要再等待 131072 周期；本批正式 runner 已证明 marker 路线可用。没有 marker 的样本仍须按内部事件或长周期规则单独验收。
- runner 现在区分 `performance_warning`、`hard_timeout_candidate` 和 `timeout_with_exception`。三分钟以内无异常的 timeout 不再被直接当成逻辑失败；功能结果、marker 缺失、异常和性能观察保持独立。
- 本批所有 Java/TypeScript 功能对照均为单线程。TypeScript 目前明显慢于 Java，但这不构成本批逻辑缺陷；后续性能工作应以 `runtime_ms / reasoning_cycle` 为主指标。
