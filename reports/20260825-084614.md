## 任务过程笔记

- 🧠 本项目的 `long` 已有 number 运行时约定；只在类型边界使用 `0 as unknown as long`，不能把时钟或周期计数整体改成 BigInt，否则会破坏现有测试和 number 运算。
- 🧠 Java 中用 `null` 表示“稍后由规则决定”的局部变量，在 strict TypeScript 中应保留运行时 `null`，用窄范围断言表达迁移契约，而不是擅自改成默认对象。
- 🧠 Java varargs `Object...` 在 jree 类型声明中要求 `JavaObject`，但原 Java 逻辑传入 primitive boolean；桥接只改变静态类型，不包装运行时值。
- ⚠️ 本批没有改变推理规则、集合判等或调度语义；仍需后续诊断批次继续收敛生产错误。
