## 任务过程笔记

- Java `TruthValue` 的 frequency 字段是 `float`，confidence 字段是 `double`；不能在 TypeScript 中用一个统一的 `number` 字符串哈希替代。
- Java `Sentence.equals` 先比较缓存 hash，再比较 TruthValue epsilon equals；因此 hash 与 equals 必须成对核对，单独修复其中一项不足以恢复 Bag 合并。
- Java 的近似 equals 会让微小数值差异进入同一个 Task/Bag key；这不是“数值看起来接近即可”的展示问题，而是直接影响推理调度的身份问题。
- 当前应继续采用 `Float32Math` 作为逐点窄边界。暂不把 TruthValue 所有字段统一改成 Float32，因为 canonical 局部 parity 仍需保持既有边界，且本批没有足够证据支持全局改动。
- 本批没有修改 Java 源码、canonical JAR、runner 验收规则或 `v0.1.0` 标签。
