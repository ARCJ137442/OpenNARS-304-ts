## 任务过程笔记

- 📌 Java 的 `Collection<?>` 在 TypeScript 中不能机械写成 `Collection<unknown>`：jree 集合方法参数具有不变性；本批使用真实的参数数组元素类型，减少了跨调用点的方差损失。
- 📌 Node 没有 Java 的 classpath `Class.getResource` 契约；资源根目录、目录遍历、过滤和排序必须集中在测试适配器中，不能把 Node 文件 API扩散到推理核心。
