   `jree-compat.ts` 使用统一 Java 字符串边界，这保留了 UTF-16/字符串值合同。
3. 下一步优先级为：补齐 Statement 重载/非法 order/空值对照；按责任簇审查
   `javaStringValue`、`javaStringHashCode`、`isJavaThrowable`、`runtimeLong`；随后审查
   `Memory`/`Bag` 的 Map、Set、迭代器和 Java equals/hashCode。Map/Set 必须继续保持抽象，
   不得以 `NativeList` 冒充 Set；每个替换要标注 Java 原类型和语义。
4. 同一责任簇闭合后再运行一次 M1-；023/024 阶段验收仍需 live canonical Java + 245+1
   全量矩阵。性能、覆盖率和 RC 不由本批提前宣称。
