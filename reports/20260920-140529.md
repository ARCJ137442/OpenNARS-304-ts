## 过程经验

- 删除一个文件的 jree import 前，必须以 `rg`/typecheck 搜完该文件所有剩余 `java.*` 和 `S` 引用；只看构造器路径会漏掉诊断文本和异常分支。
- Java `Arrays.toString(Object[])` 的可观察文本不能直接替换成 JavaScript 数组默认字符串；本批用局部 `javaArrayToString` 保留方括号、逗号空格和 null 形态。
