## 任务过程笔记

1. 事件系统使用类字面量作为 Map key 和事件标识；因此这里真正需要迁移的是“稳定 token 身份”，不是把类名字符串或普通构造函数随意替换进去。
2. `ClassTokenLike` 目前是兼容接口：它允许尚未迁移的 jree Class 与项目自有 token 处在同一 API 边界，方便按责任簇逐步去 jree；这不是全局 jree 归零声明。
3. `RuntimeObject` 的 `equals` 只保留 Java Object 身份相等这一局部契约；参与领域集合判重的实体仍须按其 Java equals/hashCode 合同单独迁移，不能复用这个边界。
4. 静态审计中的 jree 直接导入数量并不会因类型签名迁移自动归零；本批减少的是事件类实现对 JavaObject 的依赖，后续仍需逐类核对 import、调用和继承。
