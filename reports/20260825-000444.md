- Java 的 package-private/protected 访问在同一 Java package 内有效；TypeScript 的 `protected` 只允许类层级访问，跨模块同包调用必须改成 `public` 或重构访问器。当前选择 `public` 是最小合同修复，不改变函数体和调用顺序。
- 同批可见性修复会一次性消除许多级联 TS2445，但不会消除由 `null`、BigInt、jree 类型和受保护插件文件导致的其他诊断；不能用诊断下降比例代替 M2 完成。
