## 任务过程笔记

`app.keySet()` 的顺序来自 Java `LinkedHashMap`，原生数组只能承接同一有序快照；随机数来源和 `nextInt(i + 1)` 不改变。

本批与上批 `powerSet` 原生化相邻但独立：前者替换递归切分列表，本批替换洗牌列表，二者都不改变结果 `Set` 的 Java 判重契约。

本轮 benchmark 不能证明性能提升：TS 墙钟中位数较上批上升，且 Java 中位墙钟也从约 `26.697 ms/1024` 波动到约 `24.830 ms/1024`；因此只确认预算未超限，并将“原生化减少一处 jree 临时对象”作为结构性收益，不把噪声称为速度收益。

尝试为 `introduceVariables` 构造更深的直接 Narsese 单测时，parser 拒绝了候选嵌套关系；该测试输入不属于本批生产缺陷，已移除，避免把 parser 语法探索混入变量洗牌修复。
