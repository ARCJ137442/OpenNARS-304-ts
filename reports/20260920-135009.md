## 过程经验

- `Reflect` 的直接 jree 依赖实际只承担字符串包装和模板异常消息；元项递归本身不依赖 jree，适合拆成“输入边界先行、结构算法不动”的小批。
- `javaStringValue` 比 `String(value)` 更接近项目现有 Java 字符串合同；对 boxed Java String 的行为必须保留直接回归，否则类型改窄可能只在静态层通过。
- T1 risk-slice 仍不等于责任簇收口；本批不运行 M1-，也不因此宣称 J4/023 完成。
