## 任务过程笔记

- `--loader` 的实验性提示由 Node 入口参数本身产生，不能在 loader 模块内部消除；正确修复是让项目脚本使用 `--import register(...)`。
- `DEP0151` 来自 ESM 对 jree 不完整 `main: ./lib` 的扩展推断。项目 resolver 显式返回 `jree/lib/index.js` 后，source 与 dist 均不再触发该警告。
- Java String equality/hash 必须按 UTF-16 code unit 工作；直接读取 Java-like `length()/charAt()` 可以避免 TextDecoder 分配，同时保留非兼容值的转换回退。
- M3 目前只完成“一个已测量热点的 profile 与语义保持优化”这一计划项；单样本 benchmark 不能替代 M1/M2 全量门禁或 245+1 矩阵。
