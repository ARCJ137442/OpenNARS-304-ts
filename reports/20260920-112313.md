## 任务过程笔记

<!-- 任务完成过程中：在此用Markdown列表记录在任务完成过程中（或用户对话中）所积累的新知识、技能、注意事项等 -->

- `StringBuilder` 不能按“出现了 builder 就替换”为数组或模板；只有在 Java 调用面实际是单调 append、最终 `toString` 且没有共享可变状态时，原生字符串才是等价替换。
- TypeScript 的 `CharSequence` 签名仍是 Java 迁移边界的一部分；回归用例必须传 `new java.lang.String(...)`，不能用类型不兼容的原生字符串绕过公共签名。
- 这一切片不减少 direct jree import 计数，因为 `Operation` 仍依赖 Java 类型与异常边界；审计指标的稳定不等于迁移没有发生，必须结合代码合同记录具体语义变化。
- 普通 T1 切片继续复用冻结 Java 标杆，不重复启动 Java；只有责任簇收口或 023 阶段验收才升级到 M1- 或 live Java。
- 下一批按风险排序为：J4 `FunctionOperator` 的 `System.arraycopy`/数组边界与 `Operator` 的公共 CharSequence/List 边界；随后 J3 `introduceVariables` 的嵌套 Set/Map；J1 异常生产者/捕获端和桥清理继续作为独立责任簇。
