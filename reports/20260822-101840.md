## 任务过程笔记

- “Maven 命令成功退出”不能替代 Surefire 结果；当前 POM 的 `testFailureIgnore=true` 会掩盖测试失败，必须读取 `target/surefire-reports`。
- 历史 JAR 的 manifest、当前源码 commit、classes 目录和适配器 API 必须作为独立维度记录；将历史 JAR 与当前 classes 混用会产生可运行但不可归因的结果。
- JaCoCo agent 失败属于构建插件/JDK 兼容问题，不能通过修改 Java 业务语义解决；本批采用 `-Djacoco.skip=true` 继续获取可审计的编译、打包和 Surefire 证据，并明确标记环境差异。
- runner 的“有 marker”与“运行最终状态正常”不能混为一谈；当前 B1 所要求的 matched、marker 缺失、异常、超时和双方同错的独立语义仍待门禁 A 通过后处理。
- `chunk-size=1` 能够隔离单文件超时，但 Windows 子进程超时后的清理仍需专门验证；stability 曾出现 Java 子进程滞留风险，不能把超时当作无副作用的普通失败。
- 本批只修改 runner、回归测试和证据文件，未修改 TS 推理算法，因此没有制造新的迁移模式，也没有用 spec 数量或历史通过率替代总体进度。
