## 任务过程笔记

- 迁移中“缺失导入”可能只是第一层表象；导入后必须继续检查被引用 Java 平台类是否在目标运行时存在，否则会把错误从 TS2304 推迟成不可运行的兼容假设。
- Java `Runtime.exec` 的 Node 等价不是异步 Worker：本批保持同步子进程调用，符合当前单线程推理循环的行为边界，也没有引入并发内存峰值。
- Java 逐行读取 stdout 会去掉换行；Node `execFileSync` 得到完整字符串后显式移除行尾，避免仅因 API 形状变化而改变结果 Term 文本。
- `System` 是平台/外部命令边界，测试必须直接覆盖成功输出和 range，不应只依赖 tsc 证明。
- 本批仍观察到 jree 的 ESM `main` 字段弃用警告；它是 M2 交付债务，不在当前根因簇中顺手处理。
