### 语言复合项工厂

- `DifferenceExt.ts`、`DifferenceInt.ts`、`Disjunction.ts`、`IntersectionExt.ts`、`IntersectionInt.ts`：`make` 工厂对外返回 `Term | null`，保留 Java 的空结果、单项降阶和相等项拒绝语义。
- `Negation.ts`：数组重载和单项工厂均声明可空，并在逆否判断前显式检查结果。
- `Similarity.ts`：工厂返回 `Similarity | null`，补齐 `Statement` 的静态重载转发，并让 `makeTerm` 表达可空结果。

目的：使 TS 类型契约与 Java 工厂真实返回路径一致，避免以非空声明掩盖合法的 null 结果。

### 推理与操作调用点

- `CompositionalRules.ts`：复合项中间变量和 `processComposed` 参数改为可空，复用原有判空出口。
- `LocalRules.ts`、`StructuralRules.ts`：Similarity/Negation 构造结果在派发前显式判空。
- `Name.ts`、`Abbreviation.ts`：构造失败时返回空任务列表，避免创建空内容 Sentence。

目的：沿 Java null 契约闭合直接调用链，避免类型断言和空内容任务。
