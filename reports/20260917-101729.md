## 任务过程笔记

- 历史 `b9e1407` 修正的是 `TermLink` 的 Java 字符串包装边界，不证明整个 TermLink 字符串路径都可机械替换；本批仍以 Java 逐段顺序为准。
- `newKeyPrefix` 的 Java 返回类型是 `CharSequence`，但唯一消费者立即 append 后转成 `String`；只有在确认无外部依赖后，才可将它的 TS 返回类型收敛为原生 `string`。
- `Integer.toString(i + 1, 16)` 必须保持小写十六进制与 index 顺序；不能用不带 radix 的字符串化替代。
- `Array.from(typedArray, mapper).join("-")` 对本批的 `Int16Array` 足够表达 Java foreach + `StringBuilder.append('-')`；空索引必须不产生额外连字符。
