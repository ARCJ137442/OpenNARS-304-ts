## 任务过程笔记

- 📌 jree 缺失的 Java 标准类应集中放在兼容边界，不应在每个测试文件中机械声明 `any` 或伪造 namespace。
- 📌 Java `this(...)` 构造器链必须改写为一次 `super()` 加参数归一化；否则既违反 JavaScript 派生构造器规则，也会触发严格初始化诊断。
- 📌 Java varargs 在 TypeScript 中需要显式展开数组；把数组作为一个实参会改变 Bag 比较测试的运行时形状。
