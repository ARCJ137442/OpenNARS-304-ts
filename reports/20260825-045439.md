## 任务过程笔记

- 🧠 Java primitive array 在该项目的 TS 运行时不是 `number[]`：`CompoundTerm` 的矩形索引已经使用 `Int32Array`，因此 `Term` 基类应保持相同容器类型，避免继承字段互不相容。
- 🧠 `Integer.valueOf` 返回 Java 包装对象；Java 的数组赋值会自动拆箱，TS 必须调用实例 `valueOf()`，不能把包装对象直接写入 typed array。
- 🧠 Java visitor 的根调用把 `null` 作为父节点是公开契约，不应通过非空参数类型掩盖；这次只放宽父节点类型，没有改递归顺序。
- 🧠 本机出现访问冲突后，降低 Node 堆上限并保持单任务运行可使权威 tsc 稳定完成；该环境问题独立记录，不计入源码诊断。
- ⚠️ M2 仍未完成：诊断还剩 `1379` 项；`Term.nameValue` 和 `Map<Integer>` 等后续 Java/TS 边界尚待单独核对。
