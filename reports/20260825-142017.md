## 任务过程笔记

- Java 构造器参数为 `long` 时，TypeScript 侧不能用普通 number 代替；测试输入也应保持 bigint 语义。
- `InstanceType<typeof C>` 依赖构造器可见性；对 protected/private 构造器的类，测试运行时类型应使用 `instanceof C`，而不是扩大生产代码可见性。
- JavaScript 类名在运行时是值，不能在 `as` 类型位置重复使用；应通过实际构造结果和 `instanceof` 验证。
