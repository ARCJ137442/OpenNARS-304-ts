## 任务过程笔记

- Java `Object...` 是任意对象的事件 payload，不应在 TS 中强迫所有推理上下文继续结构性继承 jree `JavaObject`；事件边界可以接收 native class，再集中适配旧接口。
- 去除继承会让原先的 `override toString()` 变成普通方法；这是编译器发现的迁移副作用，不是推理语义变化。
- `DerivationContext` 位于推理引擎层，因此虽然本批没有修改算法，仍必须加入受影响 NAL smoke；本批不触发 M1- 全量的理由是只改继承和类型边界，且没有改变集合、Float32、规则或 runner 观测面。
- 普通 023 批次继续复用三次一致的 Java 冻结标杆；Java artifact、源码/classes/test-classes、依赖、夹具、runner 合同、JDK、线程、随机或配置改变时，必须重新运行 Java。
