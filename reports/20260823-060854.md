## 任务过程笔记

- Java→TypeScript 的 `equals`/`hashCode` 迁移必须成对检查，而且子类覆写（如 `CompoundTerm`）不能假定父类边界修复会自动生效。
- jree 的 `java.lang.String` 适配层不能作为 Java 字符串语义的权威实现；领域对象应在数据结构进入集合 key、概念索引和链接记录前完成精确文本转换。
- 本次修复没有改变 Java 业务语义，而是恢复了被运行时适配层破坏的 key 身份；它因此同时修复了概念数量和后续调度轨迹。
- 修复后剩余两条事件差异来自 `cat -> CAT` 概念的 TaskLink 记录/Bag 状态：Java 在该点已有记录，TS 多执行两次可观测 TermLinkSelect；后续轨迹重新对齐。该差异尚未足以支持修改调度器，下一步应采集两端 TaskLink/Bag 状态后再决定。
- Float32 收窄仍应保持在操作数进入运算的位置，并适合继续聚合为独立可测试的转换/计算函数；本批未扩大到该重构。
