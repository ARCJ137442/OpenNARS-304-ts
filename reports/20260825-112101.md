## 任务过程笔记

 - 依赖缺口应优先在项目 runtime 边界补齐。直接把 Node 对象强转为 Java 类型只能消除诊断，不能满足 `InputStreamReader` 对 `available/read` 的运行时要求。
 - Java primitive `long` 在本项目并非统一使用 bigint；时间戳相关代码已有 number 兼容约定。迁移时必须同时核对“静态类型、运行时值、既有测试断言”三层，不能只看 Java 源码字面类型。
 - `InputStream.read` 的 Java 重载在 TypeScript 中必须落到一个运行时分派实现；否则传入缓冲区时会错误地返回单个字节。
 - 首次 tsc/测试验证均使用 768 MB Node 堆上限，避免系统此前的高内存崩溃；未启动并行命令。
