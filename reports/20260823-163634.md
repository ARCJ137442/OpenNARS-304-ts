- 📌 `as float` 在 TypeScript 中会被擦除，不能表达 Java 的中间结果收窄；必须通过 `Float32Math.from/add/subtract/multiply/divide/sqrt` 明确表达。
- 📌 “Java 源码含 float”不等于“每一处都存在迁移缺陷”：字段 setter、构造器、既有适配器和最终存储可能已经完成边界收窄。审计结论应区分“已覆盖”“本批修复”“仍需运行时验证”。
- 📌 `Math.pow` 的指数仍按 Java `Math.pow` 的 double/int 提升规则处理，不能机械把所有操作数都收窄成 float；这属于已确认的语言语义例外。
- ⚠️ 本批没有处理 Java long 复合赋值的隐式截断、视觉插件既有算法问题或 TypeScript 编译诊断；这些是独立问题，避免与 float 语义修复混批。
