### 下一系列修改建议

1. `J4 Statement`：先对照 `Statement.java` 的 relation factory、异常文本和 `java.util.Arrays.toString` 观测，补直接构造/非法参数合同，再处理其剩余 `java,S` 导入；影响面大，不能只删导入。
2. `J1 javaStringValue`：按调用者分簇，优先处理只做名称/显示文本的 mental operator 或事件边界；`Task`、`Sentence`、`Item` 先保留兼容层，直到 Java String 输出和 hash/equality 合同有独立回归。
3. `J1 javaStringHashCode`：审查 `Item`、`Term`、`CompoundTerm`、`Variable` 的 Java key 合同；不把哈希函数替换成 JS identity，也不把 Map/Set 偷换成数组。
4. `J1 isJavaThrowable` 与 `runtimeLong`：先统计仍由 jree 产生的异常/long 值来源，再分别做 `TextOutputHandler` 和 `Stamp` 的窄切片；不得因当前 native exception 已通过就删除 legacy 观察分支。
