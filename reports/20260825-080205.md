## 任务过程笔记

- jree 的 `ArrayDeque` 无参/数值构造在本项目运行时会错误地走 `addAll(undefined)`，显式传入同类型空 `ArrayList` 才能得到可用空队列。
- Java 的 `long` 静态类型不能保证迁移后的实际调用方一定传入 bigint；对于跨运行时边界的时间值，应在局部运算入口归一化，而不是扩大修改全局时间模型。
- `getCurrentTaskLink()` 既被诊断轨迹读取，也被推理规则读取：前者需要 Java 的 nullable getter，后者在契约要求非空处必须显式使用 `requireCurrentTaskLink()`。
- 本批最初串行测试暴露两类运行时问题：TaskLink novelty 的 number/bigint 混算，以及未登记 TaskLink 时追踪器触发非空断言；两者均已按最小根因修复，最终串行测试 139/139 通过。
