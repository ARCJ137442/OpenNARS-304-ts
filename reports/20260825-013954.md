## 已确认事实

- Java `Terms.verifyNonNull(Collection<?>)` 是 public；`Terms.verifyNonNull(Term...)` 没有 public 修饰，是同包可用的 package-private helper。
- TypeScript 将两个 Java 方法放入同名 overload 组，并把数组 helper 声明为 protected，触发 `TS2385`；`Conjunction` 调用数组形式时还触发 overload 不匹配。
- 本批基线为 1685 项：生产 746、测试 939。
- canonical Java artifact 未改变：commit `8675b76fe8c21ee20a7b8c1b63408fb05327210d`，JAR SHA-256 为 `2CF519E1F85C38E38384C7076AA750C730580C612C97CC70C70B361361F273F5`。

## 本批决策

- 删除与 public `verifyNonNull` 同名的 protected overload。
- 新增明确的 `verifyNonNullTerms(...t: Term[])` 入口，并在同包迁移调用方 `Conjunction` 中使用它。
- 该入口在 TypeScript 中为 public，是 Java package-private 同包调用的边界适配；没有把 Java private 方法公开，也不改变空值检查逻辑。
