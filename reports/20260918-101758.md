## 任务过程笔记

- `NativeMap` 的 Map 抽象不能被数组或 List 冒充：有 hashCode 的领域对象使用候选桶，无 hashCode 的对象仍走 Java equals 全扫描；迭代顺序仍由 ordered records 维护。
- 哈希索引的维护点不只在 `put/get`：`remove`、迭代器 `remove`、`clear` 都必须同步更新索引，替换值不能改变原 key 和插入位置。
- 成功 profile 必须让 TS 子进程正常退出；被 process limit 杀掉时得到的只是 runner 空闲 profile，不能据此断言热点。
- 主机级访问冲突必须与代码异常分开记录。原始 M1- 行不改写，使用独立 retry 证据恢复该文件的功能结论。
