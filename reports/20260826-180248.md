## 修改内容汇总（git diff 行级）

本批只修改插件注册边界和对应构造器签名，不改变插件顺序、参数值、推理规则或输出格式。

### `src/io/ConfigPluginRegistry.ts`

- 移除 `jree` 运行时导入。
- 以原生字符串传入 `VisionChannel`，并把 XML 参数值直接传给 `NullOperator`。

目的：让插件注册表的 factory 保持原生 TypeScript 输入，减少无意义的 Java 字符串包装。

### `src/operator/NullOperator.ts`

- 构造器接受 `JavaStringInput`，把 Java/native 字符串兼容处理交给已有 `Operator` 边界。

目的：兼容既有 Java 字符串调用者，同时支持注册表使用原生字符串。

### `src/plugin/perception/VisionChannel.ts`

- 构造器接受 `JavaStringInput`，在进入 `Term` 前通过 `toJavaString` 收窄。

目的：保留 VisionChannel 标签的 Java 字符串语义，并允许平台中立注册代码传入原生字符串。

### `test/node/operator-boundary.test.ts`

- 增加原生字符串构造 `NullOperator("^native")` 的名称回归断言。

目的：锁定 Java/native 字符串边界的可观察名称行为。
