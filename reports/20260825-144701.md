## 任务过程笔记

- Java 类加载允许基类和子类相互引用，Node ESM 的 TDZ 不允许在子类尚未初始化时读取基类绑定；把子类构造注册为显式运行时工厂能保留同步 API，同时消除反向静态 import。
- 仅用 `LinkedHashSet` 代替 `TreeSet` 会丢失 `compareTo` 排序和比较去重，不能满足 `SimilarOutput.last()` 的行为；本批使用了更窄的比较器容器，并只暴露该调用面需要的操作。
- 解环后首个回归又暴露 jree 缺少 `TreeSet` 构造器；这证明模块加载和集合兼容是两个相邻但独立的根因，均已留下过程证据。
- Node strip-only 模式不支持 TypeScript parameter property；兼容容器使用普通字段和构造器赋值。
- jree `DEP0151` ESM 主入口弃用警告仍未处理，保留为 M2 交付债务。
