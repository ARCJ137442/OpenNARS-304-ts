## 任务过程笔记

- Java `Object... values` 在 TypeScript 中必须直接使用 rest 参数；错误的 Java 类名残留会在特定推理分支才暴露。
- Java 静态导入、重载和构造器委托是本轮重复出现的迁移模式：先按参数形状显式分派，再调用唯一的 `super`/目标静态方法。
- `.nal` 文件中的纯数字行是可执行的周期命令，不能把 CLI 的 `--cycles` 简单理解为覆盖值；这解释了 smoke 在应用语料上明显慢于局部测试。
- Node strip-only 模式不支持 TypeScript namespace；对迁移后的运行时常量，应优先使用类静态字段或普通对象，而不是保留仅为类型合并服务的 namespace。
