## 任务过程笔记

- Java 源码中的 `implements Serializable` 不会消除 Java 类的隐式 `Object` 基类；迁移到 TypeScript 时，若 jree 的 `JavaObject` 被当成结构接口实现，必须显式 `extends JavaObject` 才能保留 `getClass/hashCode/equals` 和参数可赋值关系。
- 该修复只改变继承入口和隐式基类初始化，不改变 Bag 的哈希、顺序、预算或推理算法；因此用全量 Node 单测和局部 parity 保护运行时观测面。
- 仍不能把 jree 缺少的反射/XML/网络/序列化类当作已解决；它们是后续独立诊断簇。
