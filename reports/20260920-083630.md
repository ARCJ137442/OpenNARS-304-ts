## 任务过程笔记

- Java `Arrays.equals/hashCode` 不能直接用 JS 对象身份或普通数组字符串化替代；
  `Int16Array` 的每个 short 值和 Java 31 倍累积必须有独立合同。
- `Objects.hash` 是数组哈希式 31 倍累积，不是简单 XOR；本批用项目已有的
  `javaValueHashCode`，并用直接测试锁定数值。
- 链接对象的 hash 是 Bag/TaskLink 判重的一部分，因此虽然代码修改很小，计划器仍
  正确判为 T1，并执行了 5 个推理哨兵。
- 异常桥不能仅凭“能抛出错误”判断可原生化；现有测试明确观察继承关系和
  `getMessage()`，下一批必须先保留这些合同。
- 性能数字只作为后续指标：当前 `toothbrush2` 峰值约 `903.4 MiB`，没有把它当成
  逻辑失败，也没有在语义批次中做性能重写。
