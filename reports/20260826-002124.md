## 任务过程笔记

- 🧠 Node `DEP0151` 的触发点是 ESM 对无扩展名 package `main` 的自动补全；项目自己的 `resolve` hook 可以在不改变依赖安装内容的前提下直接指向完整文件。
- 🧠 `getConverter` 只是 Node 内部编码实现的 profile 符号；性能归因必须沿调用栈写成“jree JavaString UTF-16 兼容转换经过 Node TextDecoder”，不能把运行时内部函数误归属给 jree。
- 🧪 shell 的 warning 回归只判断子进程 stderr；Node 测试器使用 `--experimental-strip-types` 时可能自身输出提示，这两类现象必须分开统计。
- 🚫 性能优化仍未开始：在没有独立语义/周期/marker 对照前，不采用 decoder 缓存或 monkey-patch。
