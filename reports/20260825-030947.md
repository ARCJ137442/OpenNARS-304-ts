## 任务过程笔记

- Java 的 `Sentence.toString(Nar, boolean)` 在 `showStamp=false` 时不会要求 stamp 文本；迁移代码若保留额外断言，会把合法调用变成异常。
- `java.lang.String` 与 Node 原生 `string` 应在 Java 集合/异常/返回值边界显式转换；字符串拼接本身保持原生 `string`，避免把 JS `.length` 与 Java `.length()` 混用。
- `java.lang.Long` 接收 `long` 的 `bigint` 值时必须显式构造，不能把 primitive `bigint` 当作 boxed `Long`。
- 串行测试仍会产生大量 jree 的模块解析弃用警告，但本批没有失败；该警告属于后续依赖/构建清理项，不应伪装成零诊断。
