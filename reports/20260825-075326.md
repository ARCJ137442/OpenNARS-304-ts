## 任务过程笔记

- Java 的 List 返回值在 temporal induction 中确实可以为 null；TypeScript 需要在消费点处理，而不是把它伪装成空列表，以免混淆“无推导”和“推导结果为空”的来源。
- `term_indices` 是可空数组，TypeScript 对属性的重复读取不能可靠保留跨表达式收窄，局部常量同时改善可读性和类型证据。
- `LinkedList` 的泛型参数在 Java 中由声明明确给出，TS/jree 构造时也应显式提供 `Task`，避免退化为 `unknown` 并传播到后续列表操作。
- 本批未观察到算法快照差异；剩余 1144 条诊断集中于其他控制、实体、推理和集合泛型文件。
