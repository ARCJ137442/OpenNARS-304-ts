## 任务过程笔记

- NAL 文件中的独立数字行不是注释或应被静默删除的输入，而是 `Nar.addCommand` 的周期控制；忽略它会造成大量早期 single-step 结果回退，必须保持 Java 的加载语义。
- `Sentence.toString(..., showStamp=true)` 属于 runner 观测面的一部分，迁移错误会先表现为异常而非 marker 差异；应先修复观测合同，再判断推理语义。
- “补 import”不是单纯编译清理：在该转换产物中，缺少 runtime import 会直接改变 Node 初始化/执行行为；但将高层 `BudgetFunctions` 引回 operator 层又会制造循环依赖。依赖方向比局部缺失更重要。
- `Reflect` 的 Java overload 在 TypeScript 中不能靠重复 `case 2` 表达，必须按运行时结构区分 Statement 与 operator-name + Term[]，同时保留 Java 的 `Term`/字符串边界。
- 245 矩阵必须看 `matched`、`error_type`、`timed_out` 和最终 `ok`；“双方都没满足 marker 但结果相同”不能计为功能通过。
