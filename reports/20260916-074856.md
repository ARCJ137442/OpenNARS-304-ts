## 任务过程笔记

- 这类短生命周期 Map 的安全前提不是“变量是对象”，而是 key 在 Java 合同中确实被拼接后的文本值；value 的 Java wrapper 仍可能影响后续 `CharSequence` 调用，因此只收窄 key，不强行改 value。
- 原生 Map 与 Java Map 的 API 形状不同：`get` 的 miss 要归一化为 `null`，`size` 是属性；迁移后必须用局部测试立即触发这些差异。
- `Bag.nameTable`、Term/Task substitution、Set/Iterator 和运行时类身份仍是领域语义容器，不能复用本批结论。
- 本机长测资源边界按单进程不超过 4GB、系统可用内存不少于 10GB 执行；功能对齐优先，性能只记录不混入本批修复。
