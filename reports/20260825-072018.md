## 任务过程笔记

- 📌 Java 的引用字段默认可为 null；TypeScript 的 strictPropertyInitialization 和 strictNullChecks 会把“尚未进入 TermLink 阶段”的状态分别暴露为 TS2564/TS2345，必须从字段到调用点完整传播。

- 🚩 对 `revise` 与 `LocalRules` 反馈路径采用 null guard，使未设置 link 时不发生解引用；实际推理路径在 link 已由 `fireTermlink` 设置时保持原有行为。
