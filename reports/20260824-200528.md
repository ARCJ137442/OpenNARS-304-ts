## 任务过程笔记

- Java 转 TypeScript 时，方法签名中的 Java 类型如果仅作为类型使用，应以 `import type` 补齐；这不会引入运行时模块边，避免了 `Memory` 与 operator 之间的循环初始化风险。
- `TS2304` 生产剩余项已缩小为 `Item/$outer`、ConfigReader 的 XML/资源 fallback 和 `System` operator 的缺失导入/运行时边界；它们不能与本批混合处理。
- jree 实际导出仍缺少 `URL`、对象流、数据报网络、`Runtime/Process`、XML DOM 和反射等 Java 标准库边界。后续必须逐类核对 Java 行为，不能直接改 `node_modules` 或用全局 `any`。
- npm 测试仍报告 jree `main` 字段扩展解析弃用警告；这是 M2 已知交付缺口，不影响本批测试退出码。
