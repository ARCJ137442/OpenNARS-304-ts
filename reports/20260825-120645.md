## 任务过程笔记

- 📌 Java `long` 在本项目中不是单一运行时表示：jree 声明为 `bigint`，OpenNARS 当前时钟路径保留数字值，指标路径还存在 Java boxed `Long`。必须按用途分别归一化，不能全局替换为 `number` 或全局强制 `bigint`。
- 📌 `Number()` 只放在明确的数字时钟、计时或评分边界；Java long 领域值仍使用 bigint，boxed `Long` 仍以对象保存。不能因声明类型相同就混合两种运行时表示。
- 📌 `JavaLongInput` 不能代表单一运行时值：jree bigint 与 OpenNARS 数字时钟必须在边界处显式转换；`addRuntimeLongValues`、`subtractRuntimeLongValues` 用于保留操作数的活动表示，避免隐式 number/bigint 混算。
- 📌 M1 矩阵启动后曾有一次资源目录缺失的 ENOENT；重启后的唯一矩阵已恢复 215/24/5/1 资源并完成 245 个主资源。该启动故障与当前源码语义分叉分开记录。
- ⚠️ 本批没有把 process limit 当作功能失败：`simpleOperationTest` 和矩阵中的高成本样本均有进度或 marker 证据；性能优化仍留在 M3，不与当前逻辑收敛混做。
