## 任务过程笔记

- Java `NALTest` 的静态配置包含 `Debug.TEST = true`；对照 harness 若遗漏该开关，会把确定性时刻 marker 误判为算法差异。
- Java 同参数重载不仅发生在工厂方法，也会发生在“继承 API + 领域重载”组合；必须保留单参数父类行为。
- Java 同包隐式依赖在 TS 中会表现为“模块能 import 但首次调用才 ReferenceError”；静态字段初始化和关系工厂是高风险入口。
- jree 的 JavaString 适配层不能直接作为领域 equality/hash 的唯一依据；Term 等核心实体需要自己的语义边界。
- NAL corpus 的“expected marker 未命中”与“Java/TS 输出不一致”必须分开报告；runner 现在同时保留 `matched[]` 和错误信息。
- application/recursive/stability 样本会造成单进程状态与内存累积，测试应按隔离分块执行；不能只看一个大分块是否结束。
