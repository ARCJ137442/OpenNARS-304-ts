## 已确认事实

- Java `Conjunction.make(Collection<Term>, int, boolean)` 是 private helper，方法体先把集合转为 `Term[]`，再调用 public 数组 overload。
- TypeScript 将该 private 签名放在 public `make` overload 组中，造成 `TS2385`；改成 public 会破坏 Java 的私有实现边界。
- 本批基线为 1686 项：生产 747、测试 939。
- canonical Java artifact 未改变：commit `8675b76fe8c21ee20a7b8c1b63408fb05327210d`，JAR SHA-256 为 `2CF519E1F85C38E38384C7076AA750C730580C612C97CC70C70B361361F273F5`。

## 本批决策

- 将 private helper 从同名 `make` 改为 private `makeFromCollection`。
- 补充与 Java 方法体等价的独立实现：`Collection.toArray` 后调用 public 数组 overload。
- 保持 `make` 的 public overload 顺序、集合扁平化逻辑和返回值不变。
