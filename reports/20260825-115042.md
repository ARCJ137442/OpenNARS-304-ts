## 任务过程笔记

- “JavaString 参数过窄”是 API 边界契约问题，不应在每个 Node 调用点机械添加类型断言；归一化应发生在进入 Java 迁移实现的边界。
- jree `JavaString.toString()` 返回 JavaString 对象，读取 native 值应使用其 `valueOf()`/`Symbol.toPrimitive`；新增测试按该实际契约断言。
- 512 MB 会使已有 5 秒 NAL runner 子进程测试出现启动耗时波动；针对性复核在 768 MB 下通过，故该失败不归因于本批字符串修改。
- M1 旧进程属于先前后台任务，已按当前“ M1 冻结、不再重跑”目标停止；冻结证据文件没有覆盖或修改。
