## 任务过程笔记

- `RuntimeObject` 的 `class/getClass` token 必须替代 JavaObject 的类身份壳；Term 的领域 equals 仍需保留并继续调用 `getClass()`。
- `CompoundTerm`、`Variable` 等子类依赖继承后的动态 constructor token；该迁移不能改动类层次或静态 SELF 初始化顺序。
- `String(term)` 是现有翻译代码实际使用的隐式 Java `toString` 边界；将其集中放入 `RuntimeObject[Symbol.toPrimitive]`，并让它调用具体类的 `toString()`，避免在 Term 缓存和文本比较处逐点散改。
- `AbstractTerm` 的 jree `Cloneable`/`Comparable` 只额外带入反射型 `JavaObject` 要求，不属于领域接口；改为项目自有的 `clone`/`compareTo` 合同后，Term、CompoundTerm、Variable 和 FunctionOperator 的 equals 参数可统一收窄为 `unknown`。
- gate 判定虽然没有要求重新启动 Java，但因源码文件数达到 6 个而要求 M1-；本次因此用冻结 Java JSONL 做 TS-only 全量保护，不把“未启动 Java”误写成 Java 现跑。
