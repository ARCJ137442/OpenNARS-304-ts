## 任务过程笔记

<!-- 任务完成过程中：在此用Markdown列表记录在任务完成过程中（或用户对话中）所积累的新知识、技能、注意事项等 -->

1. Java/TS 对照必须区分三类状态：运行时异常、超时/资源成本、marker 语义不一致；它们不能都归到“测试失败”。
2. Java 同参数重载、Java `String.equals`、48 位随机数和 Java `.class` 都是高复现率迁移模式，适合进入模式库后反复套用。
3. NAL corpus 中的内置周期命令会改变测试成本；报告命令必须同时记录夹具周期和追加周期。
4. 静态 import 虽能消除 TS2304，却可能把 Java 包级隐式依赖转换成 ESM 初始化死循环；时间推理模块需要先画清闭包再接入。
5. 本阶段继续遵守“已有实现优先、局部补丁优先”的原则；局部联测仍作为整机回归前的快速门禁。
