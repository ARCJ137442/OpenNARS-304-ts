## 任务过程笔记

- Java 允许 public 字段先保持 null，再由 main 或外部调用者注入；TypeScript 的正确迁移不是无条件 `!`，而是保留 nullable 状态并在使用入口验证不变量。
- Java `String` 的 `char` 拼接不能直接把数值码点用 JavaScript `+=` 拼接，否则会得到十进制数字文本；必须先进行字符码点转换。
