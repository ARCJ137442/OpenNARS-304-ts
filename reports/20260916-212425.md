## 任务过程笔记

- Java 的 `Collections.unmodifiableList` 是 live view；因此本批没有采用简单 `ReadonlyArray` 快照，而是让视图持有 `NativeList`/数组引用，源集合变更后 `size/get/iteration` 立即反映变化。
- 只读 view 的修改方法统一抛出名为 `UnsupportedOperationException` 的原生 Error；这样不重新引入 jree 异常类，同时保留 Java 不可修改集合的可观察失败类型。
- `Pluggable.ts` 原先只有 jree 类型导入；改为项目内原生类型后，该接口文件不再直接依赖 jree。其余 `Nar`/`Concept` 的 Java 类型仍有既有语义责任，不能据此宣称模块完全去 jree。
- 本批已经收口生产源码中实际的 `new java.util.ArrayList` 快照构造；注释中的 Java 源码示例不计入运行时依赖。M1- 用于确认这一整类快照替换不会改变推理结果。
