## 任务过程笔记

- Java `Shell` 的 `String[]` 参数在 TypeScript 边界必须显式转为 native string 进行文本判断，再通过 `S` 传给 JavaString API；不能混用原生字符串和 jree `JavaString`。
- Java 的 `Integer` id 最终传给 `Nar(long)`；本批使用 `BigInt(id)` 保持 long 边界，不把 number 直接当作 bigint。
- Java 的 `mustContainTerm` 是允许为 null 的筛选条件；TypeScript 签名、字段和分支判定必须同步表达可空性。
- jree 当前仍缺少 `System.in`、`DatagramSocket`、`InetAddress`、`DatagramPacket` 及对象流等声明/实现；这些是独立运行时适配债务，本批不伪造。
- 由于系统曾崩溃，本批所有高负载命令均串行执行；单元测试统一使用 `npm run test:serial`。
