## 任务过程笔记

- jree 的 `Memory.getOperator` 接口使用 `JavaString`，Java 源码中的字符串字面量在 TypeScript 转写后不能直接假定为兼容类型；应显式使用 jree 包装。
- Java 的 primitive cast 不能用 TypeScript 的 `as double` 模拟。当前 `long` 在 jree 类型层表现为 `bigint`，参与除法前必须显式 `Number(...)`，以保留 Java 的数值运算意图。
- 诊断总量不变不代表失败；本批先用权威快照确认基线，再定位到两个精确诊断并收敛。测试过程保持单进程，避免系统重启后再次制造内存压力。
