## 已确认事实

- jree `System` 没有 `exit` 静态 API。
- Java `Shell` 只有 3 个明确的退出点：非法配置、参数帮助后的正常结束、指定周期运行结束。
- Node CLI 的等价宿主边界是 `process.exit(status)`；不能用返回值或普通异常替代正常退出码。
- 本批基线为 1664 项：生产 738、测试 926；canonical Java artifact 未改变，SHA-256 为 `2CF519E1F85C38E38384C7076AA750C730580C612C97CC70C70B361361F273F5`。

## 本批决策

- 在 `jree-compat.ts` 增加 `javaSystemExit(status): never`，集中把 Java 退出语义映射到 Node 进程边界。
- 只替换 `Shell` 的 3 个调用点；不处理 `Logger`、stdin、网络和异常类缺口。
- 首次非增量 tsc 因主机返回 `EXCEPTION_ACCESS_VIOLATION` 且无输出，未计入结果；同一命令串行重试后得到有效诊断。
