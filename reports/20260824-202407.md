## 任务过程笔记

- Java `Item` 的无参构造器确实允许 `budget == null`，但所有预算操作在 Java 中都直接解引用；用显式 `requireBudget()` 同时保留可空数据合同和清晰的运行时失败边界。
- TypeScript 不支持当前静态字段位置的 `abstract class` 表达式。将 Java 静态内部抽象类拆成模块内抽象类，并在 `Item` 定义完成后登记，避免 TDZ/初始化顺序问题，也保留 `Item.StringKeyItem` 的使用面。
- Java 泛型 `K` 可以调用擦除后的 `Object.toString/hashCode`，TypeScript 无法从未约束泛型推导这些方法；兼容辅助函数把这条语言边界集中到一个可测试的地方。
- `VisionChannel.ts`、`TruthFunctions.ts`、`Image.ts`、`Nar.ts` 等既有工作树修改保持原状，没有纳入本批提交；`jree` 的 ESM `main` 字段弃用警告仍是已知 M2 缺口。
