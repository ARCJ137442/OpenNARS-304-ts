## 任务过程笔记

- Java 布尔 `|=` 不能简单等同于 JavaScript 的 `||`：后者可能短路右值。迁移时应先显式求值，再合并，以保持 Java 的副作用和调用顺序合同。
- 该模式可加入迁移模式库的范围目前只限“Java boolean `|=` 且 RHS 必须执行”的已验证形式；Java 数值 bitwise `|=` 不应套用本修复。
- 本批触及运行路径，但 NAL 复验未发现 marker 或功能退化；仍不能由 3 个样本推出 M1 全量没有变化。
- jree ESM 主入口的弃用警告仍存在，属于已记录的工具链债务，不在本批扩大处理。
