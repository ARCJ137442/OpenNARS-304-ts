## 任务过程笔记

- ⚠️ `nars_transitivity.nal` 的功能等价和性能合同是两个独立结论：marker/周期达标不能掩盖 32.67 倍相对慢化。
- 🧱 旧 profile 只提供候选假设；本批在当前提交重新采样后确认 `TaskLink.records` 仍是可行动的热点，才实施这一处变化。
- 🧩 优化过程记录：第一版原生 iterator 错把 Java `next()` 与 JavaScript `IteratorResult` 混在一起，导致 `TaskLink` 将包装结果当作 `Recording`；受影响测试立即暴露 `TermLink.equals` 的空对象错误。随后将 Java 风格 `iterator()` 与 `NativeDeque` 的 JavaScript `[Symbol.iterator]` 分离，局部 38 项受影响测试全部通过。按用户批准的三次失败尝试检查，本批计为 1 次适配失败尝试，最终修复后再进入 benchmark。
- 📌 当前 native deque 只承担已证实的 `TaskLink` 使用子集，不宣称替代全局 jree 集合，也不移除 `Recording` 的 JavaObject 兼容继承；后续热点仍需逐一 profile、逐一回归。
