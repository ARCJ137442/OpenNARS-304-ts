## 已确认事实

- Java 的 `TruthFunctions.revision` 有一个对外的三参数入口，以及一个仅供内部复用结果对象的四参数 private helper。
- TypeScript 原先把这两个 Java 方法放在同名 overload 组中，private overload 与 public overload 混合触发 `TS2385`；直接公开 helper 会泄漏 Java 私有实现边界。
- 本批基线为 1687 项：生产 748、测试 939。
- 当前 canonical Java artifact 仍为 commit `8675b76fe8c21ee20a7b8c1b63408fb05327210d` 的 JAR，SHA-256 为 `2CF519E1F85C38E38384C7076AA750C730580C612C97CC70C70B361361F273F5`。

## 本批决策

- 保留 public 三参数 `revision` 作为 TypeScript 对外入口。
- 将内部四参数实现拆为不同名称的 private `revisionInto` helper，由两个 dispatch 分支调用。
- 只改变 TypeScript 的 overload 表达，不改变计算公式、结果对象复用或 Java private 语义。
