## 已确认事实

- Java `Variable` 有 public 单参数构造器和 protected 双参数构造器；TypeScript 不能在同一 overload 组中表达 Java 的包级可见性，当前 public/protected/implementation 混合产生 `TS2385`。
- `Variable` 的双参数构造器在 TypeScript 其他模块的迁移路径中需要被调用；将其保留为 protected 会继续阻断类型闭合。
- 本批基线为 1688 项：生产 749、测试 939。
- `TruthFunctions.revision`、`Conjunction.make`、`Terms.verifyNonNull` 的剩余 `TS2385` 分别涉及 Java private helper，不能套用本批构造器处理。

## 本批决策

- 将 `Variable` 双参数 overload 改为 public，保持构造器参数、分派和初始化逻辑不变。
- 这是 TypeScript 访问控制模型对 Java 包级可见性的适配，不是将 Java private 方法公开，也不改变运行时行为。
