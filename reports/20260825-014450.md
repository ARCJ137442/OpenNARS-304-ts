## 已确认事实

- Java `Shell.InputThread` 是 `Shell` 的 private inner class；其构造器没有显式访问修饰符，但外层 `Shell` 在同一类内部直接调用 `new InputThread(...)`。
- TypeScript 翻译把该构造器写成 protected，导致外层 `Shell` 实例化自己的内部类时触发 `TS2674`。
- 本批基线为 1683 项：生产 744、测试 939。
- canonical Java artifact 未改变：commit `8675b76fe8c21ee20a7b8c1b63408fb05327210d`，JAR SHA-256 为 `2CF519E1F85C38E38384C7076AA750C730580C612C97CC70C70B361361F273F5`。

## 本批决策

- 将 TypeScript 内部 `InputThread` 构造器改为 public，使外层 `Shell` 能表达 Java 外层类对内部类构造器的访问。
- 不改变 `InputThread` 类本身、输入读取逻辑、线程启动方式或 `Shell` API。
