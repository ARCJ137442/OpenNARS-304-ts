## 任务过程笔记

- Java `float` 审计不能只看“最终返回值是否 `Math.fround`”。当 Java 在中间步骤已经以 float 运算时，TypeScript 需要在每个操作数/中间结果边界收窄；`Memory.output` 的 `VOLUME=9` 反例证明了这一点。
- 整数分子/整数分母的 Bag 平均优先级路径经过数值反例检查，Java 先把整数转为 float 后除法与 TypeScript 最终收窄的结果一致，因此没有为了形式统一而扩大修改。
- Java 的显式 primitive cast 不能由 TypeScript `as float` 代替；VisualSpace 的尺寸 cast 虽通常不影响小图像，但仍应在迁移层保留真实 binary32 语义。
- jree 的 Java String 比较不等同于 Java `String.compareTo`。这次排序分叉与浮点分叉是两个独立根因，必须分别用最小测试锁定。
- 单元测试通过不等于高成本 NAL 全链路通过；marker、异常、超时、运行周期和速度必须独立记录。
