## 任务过程笔记

- Java NAL 测试期望不是简单的 CLI 日志匹配；Java 测试辅助类在 `Sentence.toString(..., false)` 下存在 `stampString` 缺陷，因此适配器直接监听内部事件并使用稳定格式。
- TS 当前最大的迁移障碍是 Java 同包隐式依赖；在 TS 中必须显式建立 import 图，不能依赖全局符号。
- Java 构造器委托 `this(...)` 不能改成 `super(...)`；应转成初始化函数或工厂，否则会改变对象初始化语义。
- NAL 全量基线不应把 Java 的 65 个失败样例直接当作 TS 失败；必须保存 Java 基线结果并对差异分类。
