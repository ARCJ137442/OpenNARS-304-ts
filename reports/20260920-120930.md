## 任务过程笔记

- `List<Task>` 是 Java 的声明抽象，但本批不能仅凭声明把它改成任意数组：必须同时核对所有具体实现和调用者。当前实现只产生临时、顺序反馈，并且调用者只执行空判断和顺序遍历，故 `Task[] | null` 是有证据的窄化合同。
- `OperatorFeedback` 命名了这个变化轴，避免把数组当成通用容器，也为后续收窄 `Operator` 的 CharSequence/Object 边界保留清晰入口。
- `Anticipate` 的 `java.util.List` 类型 cast 原本掩盖了实际 `null`；收窄签名后，非增量 typecheck 及时暴露并定位到两个返回点。
- T1 仍使用冻结 Java JSONL，不现跑 Java；这只证明本批 TS 结果没有偏离冻结标杆，不证明 Java artifact 当前运行结果已再次确认。
