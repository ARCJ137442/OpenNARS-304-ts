## 任务过程笔记

- Java 浮点实现与 TypeScript number 会有微小舍入差异，因此比较数值用 `1e-5`，格式化字符串和布尔值仍要求精确一致。
- jree 的 JavaString 不能默认当作原生 JavaScript string 使用；边界上要显式 `String(...)`，或保留 JavaString 的 `equals/hashCode` 能力。
- Term/Sentence 语言模块存在静态初始化环；测试从 Sentence 根模块开始加载，避免并行首次加载造成循环依赖假失败。
- 局部算法对照只能证明已覆盖向量的语义一致，不能替代 NAL/CLI 端到端证明；Java smoke 通过也不代表 TypeScript 入口已可用。
- LeanSpec 全局 CLI 当前不可用：入口指向不存在的 `lean-spec.js`；本次仍遵守了现有报告与规格阅读流程，未手工修改 spec frontmatter。
