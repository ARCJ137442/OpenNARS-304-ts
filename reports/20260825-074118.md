## 任务过程笔记

- Java 类字段的默认值规则必须分开处理：引用字段是 null，primitive `long` 是 0，显式 `-1` 需要在 TypeScript 中写为 `-1n`，primitive `float` 的未赋值默认值是 0.0。
- Java 的数值提升不能按 TypeScript 的 `number/bigint` 表面类型直接相加；ProcessGoal 的 long→float→long 时间窗口必须明确记录每次 float 收窄和最终向零截断。
- `Float32Math` 不只是最终结果格式化工具；当 Java 两个 float 操作数参与乘法、加法或减法时，应使用聚合函数保留操作数边界。
- `Map.get` 在 Java 中可返回 null；即使业务上由前置 put 保证存在，TypeScript 仍应在消费点保留显式缺失保护，避免把迁移假设隐藏成非空类型。
- 本批未触发 NAL 语义分叉；局部 canonical parity 仍只能证明算法快照面一致，不能替代 245+1 M1 或 M2 全量验收。
