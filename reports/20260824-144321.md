## 修改内容汇总（git diff 行级）

本批只包含 018 的等价性诊断、最小修复、回归和过程证据，不包含性能优化或全局 Map 重构。

### `src/entity/Sentence.ts`

- 将 Sentence 哈希缓存从只读改为可刷新。
- 抽出 `refreshHash()`，统一按当前 Stamp occurrence 重算 Java 兼容哈希。
- 目的：避免输入阶段 occurrence 从 `-1` 变为当前时间后，旧 Sentence 与新派生 Sentence 的 hash 不一致。

### `src/storage/Memory.ts`

- 首次为输入 Stamp 设置 creation time 后，刷新所属 Sentence 哈希。
- 目的：把缓存同步放在实际改变 occurrence 的边界，避免修改时钟或推理规则。

### `src/runtime/jree-compat.ts` 与 `src/storage/Bag.ts`

- 导出并双向调用 Java 风格 `equals`，Bag 在 JS Map 操作前解析等价键。
- 目的：保持 Java equals/hashCode 语义，避免不同对象实例被错误地当作不同索引键。

### `test/node/tasklink-key.test.ts` 与 `test/node/bag.test.ts`

- 增加 Sentence 输入哈希刷新和 Bag 等价对象键合并的持久回归。
- 目的：直接锁定此前 TaskLink 分叉和通用哈希索引边界。

### `scripts/e2e/NalTraceRunner.java` 与 `scripts/e2e/NalTraceRunner.mjs`

- 补充单线程 Java/TS 事件、TaskLink、TermLink、哈希、occurrence、records 和 marker 轨迹观测。
- 目的：保留可归一化的最早分叉证据；临时对象级字段已清理。
