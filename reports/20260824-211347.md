## 任务过程笔记

- Java 的默认初始化不是可忽略的实现细节：`boolean=false`、数值缓存为 0 会直接影响严格属性初始化诊断，同时保持运行时默认行为。
- Java 允许同名重载抽象方法分散在类体中，而 TypeScript 要求抽象重载声明连续；应合并声明，不改变派生类运行时实现。
- `ConvRectangle.index_variable` 与 `term_indices` 的 `null` 是 Java 合同，不能用伪造的非空初值替代。
- 本批没有扩大到 `ConfigReader`、网络 I/O 或性能问题；这些是后续独立根因簇。
