## 任务过程笔记

- `Arrays.asList` 是固定大小但可替换元素的 List：`set` 合法，`add/remove` 应抛 `UnsupportedOperationException`；这与不可变 List 和可变 ArrayList 都不同。
- `termList` 与 `TextOutputHandler/Events` 中用于堆栈格式化的 `Arrays.asList` 是不同责任簇，不能因为同名 API 一次性迁移。
- `NativeList` 和新固定大小 List 都应保持显式 List 抽象；若底层使用数组，也必须保留 Java 的操作面和失败行为。
