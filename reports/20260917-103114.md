- 复核 `NativeSet.equals` 时发现嵌套集合还需严格遵循 Java `Set.equals` 的接收者方向；在修复前 M1- 完成后，已以独立 fix 改为由本集合执行 `containsAll`，并用非对称值对象回归锁定该合同。
- `NativeSortedSet` 原先只有排序查找能力，没有 Java `TreeSet` 所继承的 Set `equals/hashCode`；本 fix 补齐同一集合契约，并以排序 Term 集合回归锁定。

### 历史集合契约的独立 fix

前一次 `a0b3584` 的 M1- 主矩阵先以 244/244 完成功能保护，随后才修改 `NativeSet.equals`，避免把不同代码版本混入同一证据文件。本 fix 的因果依据是 Java `AbstractSet.equals` 的 `this.containsAll(other)` 方向：对于 `equals` 非对称的迁移值对象，不能反向调用另一集合的 `contains`。同时，`NativeSortedSet` 作为 Java `TreeSet` 的原生替代，补上 Set 的值相等与元素 hash 总和合同。定向测试已通过 9/9，完整串行单测已通过 241/241；修复后 M1- 主矩阵为 244/244，额外夹具为 1/1，markerless 长周期对照仍在收尾。
