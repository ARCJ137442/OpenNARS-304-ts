# OpenNARS TypeScript brand

`opennars-ts-logo.svg` is derived from the Julia-mark SVG supplied by the project owner, who authorized this adaptation. The viewBox, balance paths, line widths, pan coordinates, and overall composition remain unchanged. The Julia three-circle group and its color rules are replaced by a rounded cyan square with `TS`; the square's 72 × 72 units matches the Julia group's 76 × 70 visual bounds. The original SVG is black on white as in the reference.

This is an owner-authorized adaptation of a supplied project asset; the repository MIT license applies to the project's new contribution and does not assert ownership of the inherited artwork. The canonical file lives here and is copied byte-for-byte into the static Demo Lab at build time. OpenNARS 3.0.4 code attribution remains in the root `NOTICE`.
