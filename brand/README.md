# OpenNARS TypeScript brand

`opennars-ts-logo.svg` starts from the supplied Julia-mark SVG. The viewBox, balance paths, line widths, pan coordinates, and overall composition remain unchanged. The Julia three-circle group and its color rules are replaced by a rounded cyan square with `TS`; the square's 72 × 72 units matches the Julia group's 76 × 70 visual bounds. The original SVG is black on white as in the reference.

Only this project's new TS mark and the exact SVG differences above are new authored content; the inherited scale drawing remains the supplied artwork. The repository's MIT `LICENSE` applies to this new project contribution; do not claim that it relicenses any upstream material embedded in the source SVG. The mark is the canonical asset copied into the static Demo Lab at build time. OpenNARS 3.0.4 code attribution remains in the root `NOTICE`.
